# Reestruturacao Studio L4

Area offline para evolucao do novo site institucional da Studio L4.

## Regra de trabalho

- Esta pasta nao substitui os arquivos publicados na raiz.
- Os assets originais continuam sendo referenciados por caminho relativo.
- Publicacao, stage, commit e push dependem de aprovacao explicita.

## Arquivos

- `index.html`: nova pagina institucional offline.
- `styles.css`: sistema visual responsivo.
- `script.js`: menu, animacoes, formulario e filtros.
- `content-architecture.md`: mapa de expansao para blog, cases e area de clientes.

Para visualizar localmente, abra `index.html` no navegador.
